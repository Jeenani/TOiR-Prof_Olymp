#### Этап 2: Серверный REST API (`ToirProf.Api`, .NET 10)
Создан и скомпилирован высокопроизводительный, лаконичный REST API с открытой OpenAPI/Swagger-документацией:

1. **Аутентификация и безопасность (JWT + RBAC)**:
   * Выдача токенов JWT с `role`, `workshop_id`, `user_id`.
   * Хеширование паролей по SHA-256 (пароль тестовых пользователей: `password123`).
   * Настроен CORS (`AllowAll`) для взаимодействия с будущими Web и Desktop клиентами без блокировок браузера.
2. **Контроллеры и бизнес-эндпоинты (31 зарегистрированный маршрут)**:
   * **`AuthController`** (`/api/auth`): вход (`/login`), профиль (`/me`), справочники ролей (`/roles`), бригад (`/teams`) и цехов (`/workshops`).
   * **`EquipmentController`** (`/api/equipment`): реестр оборудования с пагинацией (25/50/100), поиском, фильтрами по цеху и статусу, карточка оборудования с историей статусов и графиком ТО, создание и обновление.
   * **`WorkOrdersController`** (`/api/work-orders`):
     * Создание заявки с автогенерацией номера формата `Z-2027-XXXX`.
     * При создании аварийной заявки (`emergency`) оборудование автоматически переводится в статус **«В аварийном простое»** с фиксацией в истории.
     * Назначение бригады (`/assign-team`) с переводом в статус «Назначена».
     * Завершение заявки (`/status` = выполнена): автоматический расчет фактического простоя в часах (`downtime_hours`), возврат оборудования в статус «В работе», списание использованных материалов со склада.
     * Добавление материалов к заявке (`/materials`).
   * **`SchedulesController`** (`/api/schedules`): календарный план ТО, фильтры по оборудованию и месяцам, кнопка «Сформировать заявку из графика» в один клик.
   * **`MaterialsController`** (`/api/materials`): складские остатки, индикатор низкого остатка (`isLowStock`), корректировка запасов.
   * **`AnalyticsController`** (`/api/analytics`):
     * Сводный дашборд KPI: 6 ключевых показателей (всего оборудования, активные заявки, выполненные заявки, суммарный простой, среднее время ремонта, соблюдение графика ТО).
     * Круговая диаграмма распределения оборудования по статусам.
     * Столбчатая диаграмма распределения заявок по цехам.
     * Рейтинг **Топ-5 оборудования по простоям**.
     * Блок предупреждений (просроченные ТО, критические остатки материалов на складах).
3. **Автоматическое тестирование (скрипт `test_api.py`)**:
   * Все 8 интеграционных тестов (Swagger, JWT логин, Auth Me, Оборудование, Заявки, KPI Дашборд, Материалы, Графики ТО) выполнены с кодом **HTTP 200 OK**.
   * Решение собрано в единый файл решения `ToirProf.slnx` без единой ошибки и предупреждения.
